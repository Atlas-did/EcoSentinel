# 第 3 部分：论文方向 —— 🔴 发现一个必须修正的问题

## 3.1 论文现状

`D:\SeaBreeze Inspector\main.tex`（67,884 字节，7 章）：

```
引言 / 系统总体设计 / 抗风悬停控制 / 巡检路径规划 /
机械臂运动学 / 叶片缺陷检测 / 讨论与结论
```

另有 `latex_thesis\main.tex`（48,177 字节）+ 11 张配图 + `main.pdf`（5 MB，**已编译**）。

**论文质量明显高于一般学生项目**：有摘要、关键词、对比文献表、BOM 成本表、产物指标体系。

## 3.2 🔴 数字不一致（我已复现并定位原因）

| 项 | 论文 `main.tex` | 仓库 README / CI |
|---|---|---|
| 抗风改善 | **最大偏离 3.20 cm → 0.12 cm，降低 96.4%** | **均值误差 0.0896 → 0.0174 m，降低 80.6%** |
| 检测模型 | **YOLOv8-Nano** | **YOLO11s** |
| mAP@0.5 | 0.577 | 仓库另有 v5.1 结果 |

**我的独立复现**：
```
cascade_feedforward=False → 0.0896 m  (8.96 cm)
cascade_feedforward=True  → 0.0174 m  (1.74 cm)
reduction = 80.6%   ✅ 精确
```

**原因定位**：这**不是简单的算错**，而是**两个不同的实验**：
- 论文引用的是**最大偏离**（max deviation），单位 cm
- 仓库 CI 测量的是**位置误差均值**（mean），单位 m
- 且**量级不同**（3.20/0.12 cm vs 8.96/1.74 cm）⇒ **不是同一组仿真条件**

> **结论：两个数字各自可能都对，但论文必须写明其测量条件**（风况、窗口、指标定义），否则读者无法复现，且与仓库自身 README 的 80.6% 冲突。

## 3.3 论文的其他风险

| 风险 | 说明 |
|---|---|
| **EVIDENCE_MAP 自曝的 ❌ 项** | README 的 `EVIDENCE_MAP.md` 自己标注：**"平台抗 6 级风（12 m/s）"被现有参数推翻**（`p_ok_12ms = 0.0%`）；实测极限约 8 m/s。**若论文仍写"6 级风"必须改** |
| **全部为 simulation-only** | `verify_scripts/RESULTS.md` 自己声明：**"全部为 simulation-only，无任何真机实测"**；`HIL_PROTOCOL.md` 标注真机路径 NOT EXECUTED |
| **检测 FPS 不达标** | 实测 CPU 推理 640→10.68 / 1024→2.28 / 1280→2.57 fps，**均未达 20 fps 目标** |
| **calm 组的 0 不能当精度** | 无扰动仿真下误差落至浮点零量级（1e-18）是**必然结果**，不含控制品质信息 |

> ✅ **值得称赞**：这个仓库**自己把这些问题写在了 `EVIDENCE_MAP.md` 和 `RESULTS.md` 里**，标注 ✅/⚠️/❌。这种诚实度很少见，**对论文送审是保护**——但前提是**论文正文与这些标注一致**。
