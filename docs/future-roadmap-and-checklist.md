# 第 2 部分：未来研究方向

## 2.1 SeaBreeze 方向（按优先级）

### 🔴 P0：补真机实测（最高优先）

**为什么**：
- `verify_scripts/RESULTS.md` 自述**"全部为 simulation-only，无任何真机实测"**
- `docs/HIL_PROTOCOL.md` 标注真机路径 **NOT EXECUTED**
- 这是论文、专利、答辩**共同的软肋**

**做什么**：
| 步骤 | 内容 | 产出 |
|---|---|---|
| 1 | HIL 半实物：OmniSim 桥接 + 真实飞控 | 首个非纯仿真数据 |
| 2 | 室内悬停：无风环境测基线精度 | 悬停 RMSE |
| 3 | 风扰测试：风扇/风洞模拟阵风 | 抗风曲线 |
| 4 | 机械臂 TCP 实测 | 定位精度 |
| 5 | 端到端巡检模拟 | 全链路时延 |

**注意**：`RESULTS.md` 已警告 **calm 组的 0 是数值必然，不能当精度**。真机测试要设计**有区分度**的实验。

### 🟠 P1：把抗风能力做到宣称水平

**现状**：`EVIDENCE_MAP` 自标 ❌ —— 设计参数下 `vmax_mean = 8.2 m/s`，**6 级风（12 m/s）成功率 0.0%**。

**路径**：
- 提高 `MAX_ACCEL`（受 Tello 物理限制，需换平台或减重）
- 改进控制律（如自适应增益调度）
- 减轻机械臂重量以释放控制余量

### 🟠 P2：检测性能优化

**现状**：CPU 推理 640→10.68 / 1280→**2.57 fps**，均未达 20 fps。

**路径**：
- 模型量化（INT8）、TensorRT / ONNX Runtime
- 输入分辨率权衡（640 已达标一半）
- SAHI 切片推理（小目标）—— 仓库已有 `A4/sahi_slice.py` 骨架

### 🟡 P3：雾天鲁棒性（海上风电真实痛点）

**现状**：`EVIDENCE_MAP` A3 标 ⚠️/❌ —— 合成雾（Koschmieder 模型）已有，但**特征一致性训练需 GPU**。

**为什么值得做**：海上风电**常年有雾**，"雾天仍能检测"是**工程上真正有价值**且**容易写出新颖性**的方向。

### 🟡 P4：机械臂闭环控制

**现状**：机械臂为**开环角度控制**（论文明确说明）。

**价值**：
- 提升 TCP 精度
- **产生新的可专利点**（闭环 + 视觉伺服）

### ⚪ P5：其他

- 多机协同巡检
- 自动换电/续航
- 叶片缺陷的定量评估（面积/深度）

## 2.2 EcoSentinel 方向

### 🔴 P0：实机标定参数

**现状**：`settings.py` 明确写 "demo 集**未被任何实测标定**"、"realistic 为**文献量级论证（非实测）**"。

**为什么最高优先**：
- 标定后能产出**干净、未公开的新技术方案**
- 直接强化候选点 E1 的可实施性
- `docs/hardware-runbook.md` 已列出标定需求

### 🟠 P1：PMV/PPD 热舒适闭环

**现状**：`docs/pmv-ppd-study.md` 已有 ISO 7730 PMV/PPD 实测 + Sinergym 交叉核对基础。

**价值**：把"节能"升级为"**热舒适约束下的节能**"，这是**学术界认可的问题定义**，且**专利上更好写**（有明确的物理量与标准依据）。

### 🟡 P2：多房间/楼宇级扩展

从单房间扩到多区域协同 —— 产生新的组合创新点。

### 🟡 P3：NDIR 真实 CO₂

当前 SGP30 输出的是**等效 CO₂（eCO₂）**，非真实 ppm。换 SCD40/41 可提升数据可信度。

---

## 2.3 一条共同的战略建议

> **建立"先申请、后公开"的流程。**

具体：
1. 新想法 → 内部记录（**私密**）
2. 评估可专利性 → 申请
3. **拿到申请号后**才提交公开仓库 / 投稿
4. 已公开的仓库**考虑转私有**（若暂无开源必要）

两个项目都已因此受损，**别让第三个重演**。
